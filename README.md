# Saisie et affichage d’un nombre

## Présentation

Ce projet est un petit exercice réalisé avec JavaScript et Node.js. Le programme demande à l’utilisateur de saisir un nombre, puis affiche la valeur saisie dans le terminal.

## Objectif de l’exercice

Cet exercice permet de découvrir comment :

-poser une question dans le terminal ;
-récupérer la réponse de l’utilisateur ;
-convertir cette réponse en nombre avec `Number()` ;
-afficher un résultat avec `console.log()`.

## Prérequis

Node.js doit être installé sur l’ordinateur.

## Installation

Aucune dépendance supplémentaire n’est nécessaire. Le module `node:readline`, utilisé pour lire la réponse dans le terminal, est fourni avec Node.js.

## Lancer le programme

Ouvre un terminal dans le dossier du projet et exécute :

    node index.js

Si ton fichier JavaScript porte un autre nom, remplace `index.js` par le nom de ton fichier.

## Exemple

Le programme demande :

    entrer un nombre:

Si l’utilisateur saisit `25`, le résultat affiché est :

    le nombre est : 25


## Technologies utilisées

-JavaScript
-Node.js
-`readline` pour lire la réponse dans le terminal
